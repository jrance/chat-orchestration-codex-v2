# PR HF-001 — Null‑Safe Telemetry Headers + Centralized Gating

## PR Title
Hotfix: Make telemetry headers null‑safe and centralize gating to prevent `AttributeError` in router and other runners

## Description
Tests fail with `AttributeError: 'NoneType' object has no attribute 'value'` when `ExecutionContext.headers.telemetry` is `None`. This PR fixes the issue **at the boundary** and **in the telemetry bus**, so **all** execution paths (router, concurrent, compile/execute, etc.) are safe without ad‑hoc per‑runner patches.

**What changes:**
1. Introduce `TelemetryLevel` enum (`none|basic|verbose`) and a robust `ExecutionHeaders.from_request()` that **always** returns a non‑None enum (defaults to `none`; invalid header values coerce to `none`).
2. Centralize gating in `telemetry.bus.publish_telemetry(ctx, event, level)` so callers never need to read `.value` on the enum.
3. Update DI to build `ExecutionContext` with these defaulted headers.
4. Replace any fragile `ctx.headers.telemetry.value == "..."` checks with enum identity comparisons.
5. Add regression tests.

This eliminates the crash reported by Codex for PR‑012 and future‑proofs other runners.

## Purpose
- Prevent null dereferences on telemetry headers globally.
- Provide a consistent way to parse and gate telemetry without duplicating logic.
- Keep tests that omit headers green.

## Scope
- Minimal and surgical; no behavior changes except making telemetry emission conditional via the centralized gate (semantically equivalent to prior intent).

## Step‑By‑Step Implementation

### 1) Add enum + defaulted headers
**`app/api/models.py`**
```python
from enum import Enum
from typing import Optional
from pydantic import BaseModel, Field
from fastapi import Request

class TelemetryLevel(str, Enum):
    none = "none"
    basic = "basic"
    verbose = "verbose"

class ExecutionHeaders(BaseModel):
    correlation_id: Optional[str] = None
    request_id: Optional[str] = None
    tenant_id: Optional[str] = None
    telemetry: TelemetryLevel = Field(default=TelemetryLevel.none)

    @classmethod
    def from_request(cls, request: Request) -> "ExecutionHeaders":
        raw = (request.headers.get("X-Telemetry") or "").strip().lower()
        try:
            level = TelemetryLevel(raw) if raw else TelemetryLevel.none
        except ValueError:
            level = TelemetryLevel.none
        return cls(
            correlation_id=request.headers.get("X-Correlation-Id") or request.headers.get("X-Correlation-ID"),
            request_id=request.headers.get("X-Request-Id") or request.headers.get("X-Request-ID"),
            tenant_id=request.headers.get("X-Tenant-Id") or request.headers.get("X-Tenant-ID"),
            telemetry=level,
        )
```

### `tests/telemetry/test_bus_gating.py`
```python
from app.api.models import ExecutionHeaders, TelemetryLevel
from app.runtime.context import ExecutionContext
from app.telemetry.bus import publish_telemetry

class _Req:
    def __init__(self, telemetry=None):
        self.headers = {}
        if telemetry is not None:
            self.headers["X-Telemetry"] = telemetry

def test_no_header_suppresses_events():
    ctx = ExecutionContext(headers=ExecutionHeaders.from_request(_Req()))
    publish_telemetry(ctx, {"type":"t"}, level=TelemetryLevel.basic)  # should not raise

def test_basic_allows_basic_blocks_verbose():
    ctx = ExecutionContext(headers=ExecutionHeaders.from_request(_Req("basic")))
    publish_telemetry(ctx, {"type":"t-basic"}, level=TelemetryLevel.basic)   # allowed
    publish_telemetry(ctx, {"type":"t-verbose"}, level=TelemetryLevel.verbose)  # suppressed

def test_verbose_allows_verbose():
    ctx = ExecutionContext(headers=ExecutionHeaders.from_request(_Req("verbose")))
    publish_telemetry(ctx, {"type":"t-verbose"}, level=TelemetryLevel.verbose)  # allowed
```
